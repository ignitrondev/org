Built for clinical software

The interface can change.
The clinical meaning cannot.

01

Data before pixels

The UI represents structured data; color and SVG paths are never the clinical source of truth.

02

Configured, not forked

Terminology, symbols, language, permissions, and workflow states belong in explicit configuration.

03

Integration boundaries

Components emit values and domain events. Your application owns identity, storage, authorization, and signatures.

04

No patient data by default

The library makes no network request and ships no hidden telemetry. Analytics must be deliberately enabled.
